# 使用指南

还没有部署 Sub2API 或配置 Cindy 服务器？先看 [新电脑与前置部署指南](SETUP.zh-CN.md)。直连供应商无需部署 Sub2API；使用本机隧道时才需要本机服务。

## 第一次打开

Windows 用户下载 Release 中的 Windows ZIP，完整解压到可写目录，再打开「LinX 远程模型管理.exe」。不要在压缩包预览中直接运行。源码版运行 `python launch.pyw`；macOS 推荐 Python 3.10+，运行 `python3 launch.pyw` 或包内启动入口。Mac 应用尚未签名、公证或经过完整真机验证。

程序以本地网页应用窗口展示，服务仅监听 127.0.0.1。Windows 优先使用 Edge/Chrome 的应用模式；缺少兼容浏览器时使用默认浏览器。再次打开会尽量聚焦已有窗口。

## 1. 服务器连接

推荐先在 Cindy 设置好远程连接，再选择「服务器连接 → 从 Cindy 选择服务器」，点击「使用并连接」。管理器读取当前电脑 Cindy 管理的 SSH 配置，不复制其他电脑的登录凭据。

手动连接时填写主机、SSH 端口和用户名。高级选项中的「私钥」是本机密钥文件路径，例如 `~/.ssh/id_ed25519`。不是登录密码，不要粘贴私钥正文。

首次使用先点击「打开 SSH 登录终端」，核对服务器指纹并完成登录。后台操作需要 SSH Key / Agent 或已有可复用认证。管理器不保存 SSH 密码。登录成功后关闭终端，回到页面连接。

首次连接会通过 SSH 查询实际账号的个人目录（root 使用 root 的个人目录），默认使用该目录下的 `.xdt-server/v1/codex-home`。需要与 Cindy 项目的 Codex HOME 对应。保存前可在高级设置中核实目录，切换账号或主机会重新检测。

## 2. 环境与更新

点击「检查并准备」检查 GNU Awk 和完整 Codex；已有可用工具会跳过。缺少工具时安装至当前账号个人目录，不执行 sudo，不替换系统 awk。自动 gawk 准备主要支持 Debian/Ubuntu，其他系统请按提示处理。

点击「检查更新」查看版本，再由你决定是否「立即更新」。下载、传输、校验与安装进度显示在对应工具卡片附近。失败后缓存会保留，可重试续传；是否能续传也取决于下载源是否支持 Range。服务器下载受限时会尝试本机下载后经 SSH 传输。

Codex 来源是 OpenAI 官方完整 package，gawk 来源是相应发行版包。更新保留旧版本。Cindy 可能要求自己的 Codex 版本，重连时可能恢复为其指定版本。

## 3. 添加供应商

1. 打开「供应商配置」，点击「添加供应商」。
2. 选择「直连中转站」或「本机 Sub2API」。
3. 输入 API 根地址和 Key，获取模型；列表不可用时可手动填写准确模型 ID。
4. 勾选要显示在菜单中的模型，保存配置。
5. 保存不会切换当前服务，按需点击「启用」。测试可选，每次只测试你选中的一个模型，可能产生少量费用。

上游需要支持 Responses。Chat Completions 专用服务需要另行提供协议转换。DeepSeek 等模型可以使用准确 ID，但实际可用性取决于服务端 Responses 和工具调用实现。

当前供应商的所选模型会同步到远程 Codex 模型目录。内部审核模型可能被 Cindy 隐藏。切换会核实运行路由；远程任务忙碌时请等待空闲，不要强制终止他人的任务。

## 4. 本机 Sub2API 隧道

先确认电脑上的 Sub2API 可用，再打开「本机 Sub2API」并连接。默认路径：

```text
服务器 127.0.0.1:18765 → 反向 SSH → 电脑 127.0.0.1:8080
```

隧道绑定服务器回环地址，无需电脑具有公网 IP。服务器仍需允许 SSH 远程转发，远程端口必须空闲。使用期间电脑、SSH 网络和本机服务都要在线。退出管理界面后后台隧道可以继续运行；停止隧道请点击对应按钮。

直连供应商不需要隧道，模型请求由服务器直接发送。

## 5. 换电脑

下载干净发行包，在新电脑 Cindy 中配置服务器 SSH 登录，再选择同一服务器和 Codex HOME。服务器上已经保存的供应商会重新读取，无需重新上传 Key。

也可使用「导出迁移包」迁移本机连接设置；它是个人备份，不能公开上传。SSH 私钥不会自动迁移，需按你自己的密钥管理方式配置；本机 Sub2API 也需另行部署或恢复。不同系统的私钥路径要重新选择。

## 6. 主题与数据

右上角太阳/月亮按钮手动切换；「自动」在本机时间 7:00 使用日间、19:00 使用夜间。窗口支持最大化与窄视口布局。

连接设置位于启动目录的 `settings.json`。状态缓存位于 Windows 的 `%LOCALAPPDATA%/CindyRemoteKit` 或 macOS 的 `~/Library/Application Support/CindyRemoteKit`；启动错误日志为系统临时目录下的 `CindyRemoteKit-startup.log`。供应商凭据留在服务器 Codex HOME 中，不是加密保险库。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 无法连接 SSH | 在 Cindy 和登录终端确认账号、端口、指纹、Key / Agent；SSH 配置中的 ProxyJump 也须可用 |
| 获取模型失败 | 核实服务器到 API 的网络、根地址、Key 权限；部分服务未实现 models 接口，可手动添加模型 |
| 本机可用，服务器不可用 | 直连检查服务器出口；隧道检查电脑服务、远程转发权限、端口占用 |
| 模型未显示 | 确认勾选并启用，核实模型目录同步状态；内部审核模型会被隐藏 |
| 下载失败 | 重试使用缓存，核实本机和服务器网络、代理及 GitHub 限流提示 |
| Cindy 更新后不兼容 | 先保留配置并检查本项目更新；不要盲目替换 Cindy 内部文件 |

提交问题时附上系统、LinX 版本、已脱敏错误文字与复现步骤；不要附 API Key、私钥、个人迁移包或真实完整日志。
